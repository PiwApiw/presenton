The Electron Linux workflow requires a `RELEASE_REPO_TOKEN` secret to publish prereleases into the separate `presenton/presenton-export` repository; the R2 sync workflow requires the `sync_r2` GitHub Environment plus `R2_ACCESS_KEY`, `R2_SECRET_KEY`, and `R2_ACCOUNT_ID` secrets; the DO deployment uses `doctl app create --spec .do/deploy.template.yaml` (or the DO CLI) to provision the stack from the template.
