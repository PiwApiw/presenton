Pure Markdown documentation tree with no code. Two thematic groupings: `macos/dev/` is a self-contained guide set for Electron app signing and distribution (Developer ID + notarization vs Mac App Store), while the root-level `.md` files are standalone deployment/operator guides for AWS Bedrock, Docker multi-arch builds, presentation generation modes (`standard`/`smart`/`both` via `PRESENTATION_GENERATION_MODE`), resource usage, and template v2. Files cross-reference each other and the repo's top-level README rather than importing shared content; there is no build step or static-site generator involved.
