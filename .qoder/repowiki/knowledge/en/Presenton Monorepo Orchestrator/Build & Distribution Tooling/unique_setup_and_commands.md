`scripts/sync-presentation-export.cjs` requires `npm` on PATH and pins the export runtime via `package.json.presentationExportVersion`; set `EXPORT_RUNTIME_VERSION=latest` or `EXPORT_CORE_ARCHIVE=<local-tgz>` to override. `scripts/rebuild_notice_all.py` auto-detects `servers/fastapi/.venv` (or `NOTICE_PYTHON_VENV`) and `servers/nextjs/node_modules` (or `NOTICE_NODE_MODULES`) to regenerate the root `NOTICE` file.
