Development requires running `npm run setup:desktop-runtime && npm run copy:templates` before `npm start` or `npm run dev`; full production build goes through `npm run build:all` (which also builds Next.js and PyInstaller-bundles FastAPI), while platform-specific signed builds use `npm run build:electron:mac:signed`, `build:electron:mas-dev`, or `build:electron:mas` with environment variables like `PRESENTON_MAC_TARGET`, `PRESENTON_REQUIRE_MAC_SIGNING`, `PRESENTON_MAS_DEV_IDENTITY`, `APPLE_API_KEY*`, etc. Source maps are uploaded via `npm run upload:sourcemaps`.
