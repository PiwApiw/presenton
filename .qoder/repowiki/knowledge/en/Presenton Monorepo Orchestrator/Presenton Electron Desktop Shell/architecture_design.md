Single-process Electron shell rooted at `app/main.ts` which is compiled to `app_dist/main.js` (declared as `main` in `package.json`). Startup sequence: resolve platform-specific Chromium switches, acquire a single-instance lock, initialize app/user-data/cache paths, bootstrap Sentry, then on `app.whenReady()` find free ports, start the embedded FastAPI server (bundled under `resources/fastapi`) and Next.js standalone server via `utils/servers.ts`, create a hidden `BrowserWindow` with `contextIsolation: true`, `nodeIntegration: false`, and a sandboxed preload (`app/preloads/index.ts`) that exposes only `env` and two `ipcRenderer.invoke` methods (`export-presentation`, `read-file`). IPC handlers are registered centrally through `app/ipc/index.ts` and split into feature modules (`export_handlers.ts`, `read_file.ts`). The preload additionally wires Sentry for renderer-side errors. All cross-platform packaging logic lives in `build.js`, an `electron-builder` configuration script that handles macOS signing/notarization/MAS profiles, Linux AppImage/deb, Windows NSIS/AppX, and post-pack hooks (chmod, prebuild pruning, Chromium normalization). Runtime helpers under `app/utils/` encapsulate concerns such as ImageMagick runtime resolution, export-Chromium bundling, user config store/env sync, update checking, memory snapshots, and safe console logging; they are pure Node/Electron utilities consumed by `main.ts`. Static assets (Tailwind CSS, fonts, images) live under `resources/ui/assets/`, while the LiteParse runner and bundled export runtime sit under `resources/document-extraction/` and `resources/export/` respectively.
